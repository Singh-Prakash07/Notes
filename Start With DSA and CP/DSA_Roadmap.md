## 🛠️ Personal Competitive Programming Setup (Ubuntu)

To stay efficient while working on your **FastAPI** projects in **Kolkata**, use this local setup:

1. **Fast I/O Template:** Use `sys.stdin.readline` to avoid TLE in Python.
2. **Local Judge:** Use the `Competitive Companion` browser extension with VS Code to run sample test cases instantly.
3. **The "LCS" Benchmark:** Since you're following Aditya Verma, do not move to Graphs until you can solve **Longest Common Subsequence** and its 5 variations (Shortest Common Supersequence, Edit Distance, etc.) without looking at notes.
